# assign 语法

## 基本格式

```verilog
assign 目标 = 表达式;
```

`assign` 是**连续赋值**：描述一根导线被永久驱动，等式在电路工作期间始终成立。

## 四个要点

### 1. 目标必须是 wire

- 输出端口没写类型时，默认就是 `wire`，可以直接被 `assign` 驱动
- 写成 `output reg y` 再用 `assign` 会报错

### 2. 右边只能是表达式

允许：信号、运算符、括号、常量。

```verilog
assign y = ~(a & b);
assign y = a ^ b ^ c;
```

不允许：`if`、`for`、赋值语句。这些属于过程块 `always`。

### 3. “连续”不等于“执行一次”

```verilog
assign y = a & b;
```

读作：y **恒等于**此刻的 a & b。a 或 b 变化时右边会自动重算，但**结果不一定变**。

例：b = 0 时 a 从 0 变 1，y 重新计算后仍然是 0。

组合逻辑描述的是“等于什么”，不是“什么时候变”。

### 4. 一个 wire 只能有一个驱动源

```verilog
assign y = a;   // 错误：y 被两个 assign 同时驱动
assign y = b;
```

硬件上相当于两个输出短接，仿真会得到 `x`（未知），实际电路会短路。

需要按条件二选一，要用 `always` + `if` 或 `? :` 三目运算符，不能靠多个 `assign`。

## 运算符区分

| 运算符 | 含义 | 结果位宽 |
|---|---|---|
| `&` | 按位与 | 与操作数同宽 |
| `\|` | 按位或 | 同宽 |
| `^` | 按位异或 | 同宽 |
| `~` | 按位取反 | 同宽 |
| `&&` | 逻辑与 | 恒 1 位 |
| `\|\|` | 逻辑或 | 恒 1 位 |
| `!` | 逻辑非 | 恒 1 位 |

单比特信号下 `&` 与 `&&` 结果相同，多位宽数据下完全不同，不要混用。

## 常用门写法

| 功能 | assign 写法 |
|---|---|
| 与 | `assign y = a & b;` |
| 或 | `assign y = a \| b;` |
| 非 | `assign y = ~a;` |
| 异或 | `assign y = a ^ b;` |
| 与非 | `assign y = ~(a & b);` |
| 或非 | `assign y = ~(a \| b);` |
| 同或 | `assign y = ~(a ^ b);` |
