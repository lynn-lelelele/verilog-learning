# 命令行基础

## 它是什么

命令行是“打字指挥电脑”的窗口。Verilog 工具链（iverilog、vvp）没有图形界面，只能这样用。

打开方式：

- VS Code 里按 `Ctrl + \``（反引号，Esc 下面那个键）
- 或开始菜单搜 `PowerShell`

## 提示符

```
PS C:\Users\19918\Documents\verilog-lab\01_basics>
```

- `PS`：当前是 PowerShell
- 中间：你现在**站在哪个文件夹**
- `>`：光标位置，在这里打字
- 打完必须按**回车**才执行

## 三条常用命令

### 1. 切换文件夹

```powershell
cd C:\Users\19918\Documents\verilog-lab\01_basics
```

- `cd` = change directory
- 后面是目标文件夹的完整路径

成功后提示符里的路径会变，没有其他输出。

### 2. 编译

```powershell
iverilog -o or_gate_tb.vvp assign.v or_gate_tb.v
```

- `iverilog`：编译器
- `-o`：表示下一个词是输出文件名
- `or_gate_tb.vvp`：生成的仿真文件
- 后面所有 `.v`：源文件，**用到哪些就列哪些**
- 成功时没有任何输出

### 3. 仿真

```powershell
vvp or_gate_tb.vvp
```

这才是真正“通电做实验”，`$display` 的输出都在这时出现。

## 三步循环

```powershell
cd 目录                        # 进入源文件所在文件夹
iverilog -o 产物 源文件...      # 编译
vvp 产物                       # 仿真
```

**每次改了任何 `.v`，都要重新执行前两步**，否则跑的还是旧版本。

## 辅助命令

| 命令 | 作用 |
|---|---|
| `dir` | 列出当前文件夹里的文件 |
| `pwd` | 显示当前所在路径 |

## 常见报错

| 报错 | 原因 |
|---|---|
| `找不到路径` | `cd` 后面地址抄错 |
| `无法将“iverilog”项识别为...` | 环境变量没生效，重开终端 |
| `No such file or directory` | 源文件名写错，或文件不在当前目录 |
| `error: ...` | Verilog 语法错误，看报错里的行号 |

记住：**命令成功时通常什么都不说**，出错才会打印内容。
