观察点：
① 送一位之后，next_state 立刻变化，但 state 要等时钟沿 才变；
② detected 永远比“命中那一刻”晚一拍，因为它只看 state；
③ 走到 S3 时再送 0，会退回 S2 而不是 S0 —— 这就是“最长后缀”规则。
// 第二段：算次态（组合逻辑）
always @(*) begin
next_state = state;
case (state)
S0: next_state = din ? S1 : S0;
S1: next_state = din ? S1 : S2;
S2: next_state = din ? S3 : S0;
S3: next_state = din ? S4 : S2;
S4: next_state = din ? S1 : S2;
endcase
end
// 第一段：时钟沿上搬运
always @(posedge clk)
state <= next_state;
// 第三段：输出（Moore）
assign detected = (state == S4);
