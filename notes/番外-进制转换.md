# 番外：进制与转换（Verilog 版）

> 主线笔记里的所有例子都涉及进制，这篇单独讲清楚：怎么写、怎么读、怎么换。

## 1. 为什么硬件是二进制

一根导线只有两种稳定状态：有电压、没电压，对应 `1` 和 `0`。所以电路内部存的和算的，全是 0 和 1。

十六进制、十进制只是**给人看的写法**。`8'hA5` 和 `8'b1010_0101` 描述的是同一根 8 位线上的同一组电平，编译器负责翻译。

## 2. Verilog 字面量的完整格式

```
位宽'进制 数值
```

| 部分 | 写法 | 说明 |
|---|---|---|
| 位宽 | `4`、`8`、`16` | 省略时默认 **32 位** |
| 单引号 | `'` | 分隔位宽和进制，不能省 |
| 进制 | `b` / `o` / `d` / `h` | 二 / 八 / 十 / 十六 |
| 数值 | `1010`、`A5`、`165` | 下划线可随意加，只为好读 |

同一个值 `165` 的四种写法：

```verilog
8'b1010_0101    // 二进制
8'o245          // 八进制
8'd165          // 十进制
8'hA5           // 十六进制
```

四种写法在仿真里完全等价。**选哪个只看哪种更好读**：位操作看二进制，地址和内存看十六进制。

## 3. 二进制 ↔ 十六进制：4 位一组

这是最常用的转换，记住这张表就够：

| 十六进制 | 二进制 | 十六进制 | 二进制 |
|---|---|---|---|
| 0 | 0000 | 8 | 1000 |
| 1 | 0001 | 9 | 1001 |
| 2 | 0010 | A | 1010 |
| 3 | 0011 | B | 1011 |
| 4 | 0100 | C | 1100 |
| 5 | 0101 | D | 1101 |
| 6 | 0110 | E | 1110 |
| 7 | 0111 | F | 1111 |

转换规则：**从右往左，每 4 位二进制换成 1 位十六进制**。

```
1010_0101  →  A    5   →  8'hA5
```

反过来也一样，1 位十六进制拆成 4 位二进制即可：

```
8'hCB  →  C=1100, B=1011  →  1100_1011
```

## 4. 二进制 ↔ 八进制：3 位一组

规则相同，只是分组长度变成 3 位：

```
101_011  →  5, 3  →  3'o53
```

八进制在 Verilog 里很少用，因为位宽常常不是 3 的倍数，分组容易错位。十六进制的 4 位一组和字节（8 位）天然对齐，所以更常用。

## 5. 二进制 ↔ 十进制：权重法

给 8 位数的每一位标上权重，从右到左依次是：

```
位号 :  7   6   5   4   3   2   1   0
权重 : 128 64  32  16   8   4   2   1
```

**二进制转十进制：把值为 1 的那些位权重加起来。**

```
1010_0101
= 128 + 32 + 4 + 1
= 165
```

**十进制转二进制：两种方法。**

方法一，凑权重：`165` 先减最大能减的 `128`，剩 `37`；再减 `32`，剩 `5`；再减 `4`，剩 `1`；再减 `1`，剩 `0`。被减过的位写 1，其余写 0：

```
128 64 32 16 8 4 2 1
 1   0  1  0 0 1 0 1   = 1010_0101
```

方法二，除 2 取余，余数倒着写：

```
165 ÷ 2 = 82 余 1   ← 最低位
 82 ÷ 2 = 41 余 0
 41 ÷ 2 = 20 余 1
 20 ÷ 2 = 10 余 0
 10 ÷ 2 =  5 余 0
  5 ÷ 2 =  2 余 1
  2 ÷ 2 =  1 余 0
  1 ÷ 2 =  0 余 1   ← 最高位
```

从下往上读余数：`1010_0101`。和小数转二进制用“乘 2 取整”类似，只是方向相反。

## 6. 位宽决定能装多大的数

n 位二进制能表示 `0 ~ 2^n - 1`：

| 位宽 | 范围 | 例子 |
|---|---|---|
| 4 位 | 0 ~ 15 | `4'hF` |
| 8 位 | 0 ~ 255 | `8'hFF` |
| 16 位 | 0 ~ 65535 | `16'hFFFF` |

超出范围就会被**截断或补零**，而且**不报错**：

```verilog
wire [7:0] y;
assign y = 4'b1111;    // 左边宽 → 高位补 0 → 0000_1111
```

```verilog
wire [3:0] z;
assign z = 8'hA5;      // 左边窄 → 砍掉高 4 位 → 0101，也就是 5
```

这类问题在仿真里静默发生，是最常见的低级错误来源，所以写代码时**两边位宽尽量对齐**。

## 7. 仿真输出里的格式符

`$display` 决定用什么进制看数据：

| 格式符 | 输出 | 例子（值为 8'hA5） |
|---|---|---|
| `%b` | 二进制 | `10100101` |
| `%o` | 八进制 | `245` |
| `%d` | 十进制 | `165` |
| `%h` | 十六进制 | `a5` |

```verilog
$display("b=%b d=%d h=%h", 8'hA5, 8'hA5, 8'hA5);
// 输出：b=10100101 d=165 h=a5
```

同一个值不用改代码就能换角度看，调试时非常有用。

## 8. 常见的四个坑

**坑 1：省略位宽默认 32 位**

```verilog
assign y = 'hA5;    // 不是 8 位，是 32 位，再隐式截断成 8 位
```

写法能跑，但容易掩盖位宽问题，建议永远写全。

**坑 2：位号从右往左数**

```
位号 : 7 6 5 4 3 2 1 0
```

`a[1:0]` 是**最右边**两位，不是最左边。取位错一位，整个结果就废了。

**坑 3：进制字母写错**

```verilog
8'HB    // 错：进制字母必须小写，B 会被当成数值的一部分
```

**坑 4：十六进制「一位」对「四位」**

`8'hA5` 是 2 位十六进制字符，对应 8 位二进制。写 `8'hA5F` 就超了，会被截成 `5F`。

## 9. 自测

1. `8'h3C` 的二进制是多少？十进制是多少？
2. `4'b1011` 换成十进制是多少？
3. `6'b11_0101` 这个写法里，最高两位是什么？为什么这样写更清楚？

<details>
<summary>答案</summary>

1. `0011_1100`，十进制 60（32 + 16 + 8 + 4）。
2. 11（8 + 2 + 1）。
3. 最高两位是 `11`。下划线把高位和低位分开，读的时候不容易数错位——这只是给人看的，仿真器会忽略下划线。

</details>
